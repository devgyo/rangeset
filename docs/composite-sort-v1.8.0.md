# 综合排序 v1.8.0

目录搜索和筛选后、分页前执行综合排序。

| 层 | 条件 |
| --- | --- |
| A | 四格中至少三格有值，且无降级条件 |
| C | 四格中少于三格有值，或已停产且未触发 D |
| D | 官网明确售罄，或已知尺码×颜色组合的在库比例低于 50% |

D 优先于 C。停产读 `products.status = 'discontinued'`，沿用现有 `manual_overrides` 中 `field = 'status'` 的覆盖规则。停产且还有库存归 C，明确售罄或低于 50% 归 D。停产但库存未公布时归 C。四格以现有卡片规则计数，明确的 N/A 与主面料的成分回退均计入。排序继续使用现有库存数据。

同层按层内商品数为品牌分配权重，使用平滑加权轮询交错。品牌队列先按已知发布季从新到旧排，缺季排在已知季之后。同季按款式族聚合，名称及 slug 打破并列。发布季不决定分层。

既有研究和 v1.6.0 数据见 [综合排序 v1.6.0](composite-sort-v1.6.0.md)。

## 双品牌样本验证

同一份本地双品牌目录中，硬壳 A 层为 Arc’teryx 59 款、Mammut 59 款。浏览器首屏实测各 12 张卡。该快照的 v1.7.0 首屏是 Arc’teryx 24 张、Mammut 0 张。当时的季节分层会把无已知发布季的款式放到后面。

## 线上基线与测试分支

当前公开站硬壳首屏为 Arc’teryx 23 张、Mammut 1 张。v1.8.0 用 Neon 测试分支的同一目录副本构建，在浏览器实测 Arc’teryx 12 张、Mammut 12 张。测试分支 A 层分别为 58 和 59 款。
