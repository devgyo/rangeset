# Rangeset 多语言风格规则 v0.1（zh-Hans / ja）

适用：字段名、分组名、符号说明、界面短语、? 说明。品牌原文证据保留在内部，前台界面不展示。

## 1. 通用原则
- 术语以 `glossary.csv` 为准，同一概念全站只用一个词。新增词先进术语表，再进页面。
- 不逐字直译，选当地户外圈和官方中/日文站实际用的说法（例：Pit zips → 腋下透气拉链 / ピットジップ）。
- 不翻：品牌名、商品名、系列名、技术名、商标（GORE-TEX、Fortius、RECCO、Coreloft、Drop Hood、bluesign…），保留 ®/™ 的位置规则与英文站一致。
- 行话保留原写法：100D、3L、2.5L、DWR、UPF、RET、PFAS、FC0。第一次出现的位置配 ? 说明。
- 短句，陈述事实，不营销：不用“极致”“卓越”“黑科技”“圧倒的”“最強”。不用感叹号。
- ? 说明：1–2 句，先说“是什么”，再说“看数字时要注意什么”。不写好坏判断。

## 2. 简体中文
- 语气：中性、口语化但专业，像懂行朋友解释。不用“您”，界面句不加主语。
- 标点：全角中文标点（，。：；？）；括号用全角（）包中文，半角 () 包纯英文/数字。省略号用“…”。
- 中文与英文/数字之间加一个半角空格：`2026 春夏`、`最多对比 4 款`、`PFAS 声明`。
- 数字与单位之间加一个半角空格，与英文站一致：`460 g`、`136 g/m²`、`77 cm`、`20,000 mm`。
- 例外（紧贴）：`100%`、`80D`、`3L`。
- 数字：阿拉伯数字，千位用英文逗号；范围用 en dash `2–4`。
- 价格：`$650 USD` 原样（币种不翻）。
- 符号说明：`● 有` / `○ 无` / `— 未公布` / `不适用`（N/A 在中文界面直接写“不适用”）。
- 季节：`2026 春夏`、`2026 秋冬`、`2026 秋季`（品牌只说 Fall 就不扩成秋冬）、只知年份写 `2026 年`、未知 `—`。
- 性别：男装 / 女装 / 男女同款。

## 3. 日本語
- 语气：です・ます体只用于完整句子（空状态、提示）；字段名、按钮、标签用体言止め（「比較に追加」「違いのみ表示」）。
- 片假名与长音：按 Arc'teryx JP / Montbell 现行写法（フィルパワー、ピットジップ、ヘルメット対応フード、ジッパー）；不混用「ジップ/ファスナー」，统一「ジッパー」（ピットジップ为固定说法例外）。
- 标点：全角「、。」「（）」；中点「・」用于并列（サイズ・フィット）。区切り「·」仅在与英文站同版式的提示行使用。
- 英数字：半角；日文与英数字之间**不加空格**（`2026年春夏`、`最大4点`、`PFASに関する表示`），数字与单位之间沿用英文站一个空格（`460 g`、`20,000 mm`）。百分号、D、L 紧贴。
- 范围：`2〜4`（波浪线）。
- 符号说明：`● あり` / `○ なし` / `— 未公表` / `対象外`。
  - 注意：日本对比表惯用 ◯=あり、×=なし（见 arcteryx.jp 对比表）。我们 ○=明确没有，与日本习惯相反，**日文版不得只显示符号**，必须带文字。v1 使用 `○ なし`。
  - 「非公開」有“刻意不公开”的含义，不用；用「未公表」。
- 季节：`2026年春夏`、`2026年秋冬`、`2026年秋`、只知年份 `2026年`、未知 `—`。业内缩写 26SS/26FW 不对用户显示。
- 性别：メンズ / ウィメンズ / ユニセックス（Arc'teryx JP 用法，不用「レディース」）。
- 价格：英文站价格原样；不要自动加「(税込)」。

## 4. 单位与格式（两种语言相同）
- 重量 g；面料/棉克重 g/m²；长度 cm；静水压 mm；蓬松度沿用英文站单位 cu in/oz（needs_review：中文消费者常写 `850 蓬`，日文常写 `850FP`；建议数值格式与英文站一致，在 ? 说明里写出本地叫法）。
- 透湿：g/m²/24h 与 RET 分开写，并带测试方法；不换算。

## 6. 质量检查
- 程序检查：页面文案里出现术语表 en 原词但未用规定译名 → 报错；“不翻”词被翻译 → 报错。
- 反向翻译抽查 ? 说明；日文由户外母语者过一遍高频页（详情页、对比页）。
